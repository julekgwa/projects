# useOnboarding Hook

The `useOnboarding` hook provides programmatic control over the onboarding flow.

## Basic Usage

```jsx
import { useOnboarding } from 'react-native-app-onboard';

const OnboardingControls = () => {
  const {
    currentPage,
    nextPage,
    isDone,
    progress,
    scrollTo,
  } = useOnboarding();

  return (
    <View>
      <Text>Page {currentPage + 1}</Text>
      <Button
        title={isDone ? 'Finish' : 'Next'}
        onPress={nextPage}
      />
    </View>
  );
};
```

## Available Values

| Value | Type | Description |
|-------|------|-------------|
| `currentPage` | `number` | Current page index |
| `setCurrentPage` | `(page: number) => void` | Set current page **state only** — does not scroll. Use `nextPage`/`previousPage`/`scrollTo` to navigate. |
| `scrollEnabled` | `boolean` | Scrolling enabled state |
| `enableScroll` | `(enabled: boolean) => void` | Enable/disable scrolling |
| `flatListRef` | `React.RefObject<FlatList>` | FlatList reference |
| `setFlatListRef` | `(node: FlatList \| null) => void` | Callback ref for the FlatList (used internally; prefer `flatListRef` for reads) |
| `width` | `number` | Resolved page width (`width` prop, or screen width when unset) |
| `numberOfScreens` | `number` | Total screens count |
| `nextPage` | `(animated?: boolean) => void` | Go to next page |
| `previousPage` | `(animated?: boolean) => void` | Go to previous page |
| `scrollTo` | `(page: number, animated?: boolean) => void` | Scroll to page |
| `progress` | `number` | Progress as a percentage (`0`–`100`) |
| `isDone` | `boolean` | Onboarding complete |
| `pauseAutoPlay` | `() => void` | Pause autoplay |
| `resumeAutoPlay` | `() => void` | Resume autoplay |

> **Note:** `progress` is a plain number from `0` to `100`, not an `Animated.Value` — use it directly (e.g. ``width: `${progress}%` ``).

## Examples

### Progress Indicator

`progress` is a plain number (`0`–`100`), so you can use it directly as a
percentage width:

```jsx
const ProgressBar = () => {
  const { progress } = useOnboarding();

  return (
    <View style={styles.progressContainer}>
      <View style={[styles.progressBar, { width: `${progress}%` }]} />
    </View>
  );
};
```

> The component also ships a built-in progress bar — set
> `paginationStyle="progress"`. See [Pagination](/app-onboard/features/pagination).

### Custom Navigation

```jsx
const Navigation = () => {
  const { currentPage, numberOfScreens, scrollTo } = useOnboarding();

  return (
    <View style={styles.navigation}>
      {Array.from({ length: numberOfScreens }).map((_, index) => (
        <TouchableOpacity
          key={index}
          onPress={() => scrollTo(index)}
          style={[
            styles.dot,
            currentPage === index && styles.activeDot,
          ]}
        />
      ))}
    </View>
  );
};
```

### Scroll Control

```jsx
const ScrollControls = () => {
  const { enableScroll, scrollEnabled } = useOnboarding();

  return (
    <View>
      <Switch
        value={scrollEnabled}
        onValueChange={enableScroll}
      />
      <Text>
        Scrolling: {scrollEnabled ? 'Enabled' : 'Disabled'}
      </Text>
    </View>
  );
};
```

### Autoplay Controls

```jsx
const AutoplayControls = () => {
  const { pauseAutoPlay, resumeAutoPlay } = useOnboarding();

  return (
    <View style={styles.row}>
      <Button title="Pause" onPress={pauseAutoPlay} />
      <Button title="Resume" onPress={resumeAutoPlay} />
    </View>
  );
};
```

### Previous / Next Navigation

```jsx
const Navigation = () => {
  const { previousPage, nextPage, currentPage, numberOfScreens } =
    useOnboarding();

  return (
    <View style={styles.row}>
      <Button title="Back" onPress={previousPage} disabled={currentPage === 0} />
      <Button
        title="Next"
        onPress={nextPage}
        disabled={currentPage === numberOfScreens - 1}
      />
    </View>
  );
};
```
