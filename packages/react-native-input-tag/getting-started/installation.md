# Installation

## Using npm

```bash
npm install react-native-input-tag
```

## Using yarn

```bash
yarn add react-native-input-tag
```

## Using bun

```bash
bun add react-native-input-tag
```

## Requirements

- React Native >= 0.79
- React >= 16.8

## Cross-Platform Support

The package works on:
- iOS
- Android
- Web (via React Native Web)
